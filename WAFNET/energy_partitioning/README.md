# WAFNET energy partitioning — side analysis

**This is not part of the FLUXNET Annual Paper 2026.** It is a standalone
West Africa Flux Network (WAFNET) analysis of energy partitioning across a
humid-to-Sahelian gradient. Requested by David Moore, 2026-09-08.

Everything for this analysis — code, data, figures, tables, and the methods
memo — lives under this directory (`WAFNET/energy_partitioning/`). Nothing
here reads from or writes to the repo-root `R/`, `scripts/`, `outputs/`,
`review/`, or `docs/` directories used by the Annual Paper, with one
deliberate exception: `code/` reads (never writes) the existing per-site BIF
metadata under the repo-root `data/extracted/` for ancillary site
information (canopy height, land cover, heat-flux instrumentation), by the
user's own choice — see `docs/methods_memo.md`.

## Sites

Six sites spanning a humid-to-Sahelian gradient:

| Site ID | Name | Country | IGBP |
|---|---|---|---|
| `GH-Ank` | Ankasa | Ghana | EBF |
| `BJ-Db1` | Dangbo | Bénin | CRO |
| `BJ-Bfg` | Bellefoungou | Bénin | DBF |
| `BJ-Nhu` | Nalohou | Bénin | SAV |
| `SN-Nkr` | Niakhar | Sénégal | CRO |
| `SN-Dhr` | Dahra | Sénégal | GRA |

## Data

Half-hourly (HH) eddy covariance and meteorological data, downloaded and
extracted fresh from the FLUXNET Shuttle (`flux_listall()` +
`flux_download()` + `flux_extract(resolutions = "h")`) into
`data/raw/`, `data/extracted/`, `data/processed/` (all gitignored, all
scoped to this analysis via a local `FLUXNET_DATA_ROOT` override — see
`code/00_config.R`). The repo-root `data/` tree, which only holds
YY/MM/DD-resolution extracts for the Annual Paper, is never touched.

## Directory layout

```
code/       R scripts, numbered in run order
data/       raw/, extracted/, processed/ (gitignored; regenerated by code/)
figures/    plots (git-tracked)
tables/     CSV outputs (git-tracked)
docs/       methods_memo.md — every filtering decision and assumption
logs/       nohup logs from long-running download/extract steps (not git-tracked)
```

## Run order

```
code/00_config.R                          # sourced by every other script; not run directly
code/01_download_extract_hh.R             # Shuttle download + HH extract, these 6 sites only
code/02_read_hh.R                         # per-site HH RDS + combined RDS
code/03_report_variables_and_closure.R    # pre-analysis report: variables, site-years,
                                           # energy balance closure, G instrumentation
                                           # (STOP HERE pending PI sign-off — see memo)
```

Scripts 04+ (aridity framing, variance decomposition, surface conductance)
are added only after the report in step `03` has been reviewed.
