FIGURE LEGEND — fig_dur11_CumulativeSiteYears_IGBP.png
========================================================

TITLE: Cumulative FLUXNET site-years by IGBP vegetation class, with
historical dataset trajectories

DESCRIPTION:
Stacked-area chart showing the cumulative number of site-years of observed
data contributed by the FLUXNET Shuttle network over time (1991–2024),
partitioned by IGBP vegetation class. Three additional lines trace the
cumulative site-years reached by three prior static FLUXNET data releases
(Marconi 2000, La Thuile 2007, FLUXNET2015) as historical reference
trajectories, each directly labelled at its final (peak) year rather than
via a legend. Vertical dashed grey lines mark the three historical release
years (2000, 2007, 2015). No plot title is rendered.

AXES:
  X — Year (calendar year, 1991–2024; breaks every 5 years)
  Y — Cumulative site-years: a running total, over calendar year, of
      site-years in which ANY flux variable has data — not a QC-gated or
      "usable" count, just data presence. Summed across all sites and, for
      the Shuttle stack, all IGBP classes. See PRESENCE RULE below for the
      exact definition.

PRESENCE RULE (exactly as implemented in R/utils.R::compute_site_year_presence(),
used for every Shuttle site-year in this figure):
A site-month is "present" if at least one of 12 flux variables is non-NA that
month: NEE_VUT_REF, NEE_CUT_REF, GPP_NT_VUT_REF, GPP_DT_VUT_REF,
GPP_NT_CUT_REF, GPP_DT_CUT_REF, RECO_NT_VUT_REF, RECO_DT_VUT_REF,
RECO_NT_CUT_REF, RECO_DT_CUT_REF, LE_F_MDS, H_F_MDS. `n_months_present`
counts how many of a site-year's 12 months meet this; `has_data` is
`n_months_present > 0`. A site-year is included in this figure's cumulative
count when `has_data` is TRUE. This is a RAW PRESENCE rule, computed from
the DuckDB `monthly` table (dataset = 'FLUXMET', unfiltered) — no QC
threshold is applied (unlike, e.g., Figure 4's tower values, which also
require passing QC_THRESHOLD_YY). Gap years with zero qualifying months are
still present as explicit rows (`has_data` = FALSE), not omitted, so the
underlying table shows operational gaps rather than silently skipping them.

Four-sided black tick marks (inward) are drawn on all axes via a duplicated
secondary axis with no labels; only the primary (bottom/left) ticks carry
text.

by IGBP class using a palette scoped to this figure (fig1b_igbp_colours in
fig_cumulative_siteyears_igbp(), R/figures/fig_network_growth.R), reused

which 7 + 9 + 2 = 18 towers do report) and silently dropped those 18 towers
from every prior build of this figure. The fix is scoped to this one
figure, not the shared constants: IGBP_order has 7 other callers across
R/figures/ (fig_igbp.R, fig_environmental_response.R, fig_latitudinal.R,
fig_growing_season.R, fig_climate.R, fig_timeseries.R) plus 2 scripts
(00_diagnostics.R, investigate_badm_management.R) not audited by this fix
-- see SESSION_LOG.md 2026-10-02 for that full list and the per-class
site-year counts below. The 15 classes plotted (ENF, EBF, DNF, DBF, MF,
CSH, OSH, WSA, SAV, GRA, WET, CRO, CVM, BSV, SNO; forests stacked at the
bottom in dark green) are exactly the 15 the current 781-site network
reports -- every key in the legend has at least one tower behind it, and no

dataset lines use a separate qualitative palette (Marconi green #2ECC71, La
Thuile red #E74C3C, FLUXNET2015 blue #3498DB) and are labelled directly on

EXCLUSION NOTES:
Historical dataset "active year" counts are computed by expanding each
site's [first_year, last_year] span to one row per active year and summing
per calendar year — this is a span-based estimate for the three historical
datasets, not an observed-data-presence count (unlike the Shuttle series,
which uses the presence table's has_data flag). This distinction means the
Shuttle and historical series are not perfectly like-for-like, and is a
known caveat carried over from the underlying figure function.
